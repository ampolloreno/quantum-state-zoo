A field guide to quantum information

Every specimen has an explicit mathematical construction, an operational task, a dimension statement, a minimality qualification, and a primary-source reference. The smallest example depends on what is being minimized and which operations are allowed.

Editorial status: This is a reconstructed starter edition. Claims, primary-paper attributions, and minimality scopes should be reviewed before it is treated as a definitive scholarly reference. Reference links sometimes point to an early source or a useful survey rather than the first discovery.

Contribute

This is a living reference: propose a correction, improve a proof, add a primary citation, or suggest a provably minimal construction through a GitHub pull request. The repository owner reviews changes before publication.

Each claim of minimality should specify its allowed operations, the quantity minimized, and either a proof or an exact literature citation.
